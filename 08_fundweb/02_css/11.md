# Estilização - Imagens



No CSS, é possível **estilizar imagens inseridas diretamente na página** utilizando a tag `<img>`. Diferentemente das imagens utilizadas como plano de fundo, as imagens inseridas com `<img>` fazem parte do conteúdo da página e podem receber diferentes propriedades para controlar **tamanho, proporção, posicionamento, bordas, arredondamento e comportamento em diferentes telas**.

A seguir, serão apresentadas as **principais formas de estilização de imagens**, com **exemplos práticos**, facilitando a compreensão e a aplicação desses conceitos em projetos reais.

Para demonstrar as estilizações, vamos utilizar o código HTML abaixo:

**Exemplo:**

```html
<!DOCTYPE html>
<html lang="pt-br">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Página Exemplo</title>
  </head>
  <body>
    <div>
      <h1>Título do Texto</h1>

      <img
        src="https://i.imgur.com/Fq6kGS8.jpg"
        alt="Imagem de exemplo"
      />

      <h2>Subtítulo do texto</h2>

      <p>
        Lorem ipsum dolor sit amet, consectetur adipiscing elit. Pellentesque
        finibus tincidunt sapien, ac scelerisque sapien tempus eget. Mauris sed
        lacus arcu. Nunc vulputate diam purus, a ullamcorper nibh pharetra ut.
      </p>
    </div>
  </body>
</html>
```

Por meio da tag `<img>`, podemos inserir uma imagem como parte do conteúdo da página. O CSS oferece diversas propriedades para **controlar suas dimensões, proporções, bordas, alinhamento e aparência**.

Nos exemplos a seguir, utilizaremos algumas imagens, que serão inseridas diretamente no HTML.



## 1. **Definir Largura e Altura da Imagem**



As propriedades `width` e `height` permitem definir as dimensões de uma imagem.

```css
img {
  width: 500px;
  height: 300px;
}
```

**Resultado:**

![](https://i.imgur.com/iWx2nbJ.png)

A imagem será exibida com **500 pixels de largura** e **300 pixels de altura**.

É importante observar que, ao definir valores diferentes da proporção original da imagem, ela poderá ficar **esticada ou comprimida**.

Por isso, geralmente é melhor definir apenas uma das dimensões e deixar a outra ser calculada automaticamente:

```css
img {
  width: 500px;
  height: auto;
}
```

**Resultado:**

![](https://i.imgur.com/JSMo1WS.png)

No exemplo acima, a largura será definida como `500px` e a altura será ajustada automaticamente para **preservar a proporção original da imagem**.



## 2. **Controlar o Tamanho Máximo da Imagem**



A propriedade `max-width` permite definir uma largura máxima para a imagem.

Essa propriedade é especialmente importante para criar imagens **responsivas**, que se adaptam ao tamanho disponível na tela.

```css
img {
  max-width: 50%;
  height: auto;
}
```

**Resultado:**

![](https://i.imgur.com/JSMo1WS.png)

Com `max-width: 50%`, a imagem poderá ocupar até **50% da largura disponível do elemento pai**, mas nunca ultrapassará esse limite.

Essa é uma das formas mais comuns de tornar imagens adaptáveis a diferentes tamanhos de tela.

Por exemplo, se a imagem possui `1200px` de largura, mas o elemento que a contém possui apenas `600px`, a imagem será reduzida para caber no espaço disponível.

Já em uma tela maior, a imagem poderá utilizar novamente suas dimensões naturais, desde que exista espaço suficiente.



## 3. **Ajustar o Enquadramento da Imagem**




A propriedade `object-fit` controla como o conteúdo de uma imagem deve se ajustar dentro das dimensões definidas para o elemento.

**Valores comuns:**

- `fill`: valor padrão. A imagem ocupa todo o espaço, podendo alterar sua proporção
- `contain`: mantém a proporção e exibe toda a imagem
- `cover`: mantém a proporção e preenche todo o espaço, podendo cortar partes da imagem
- `none`: mantém o tamanho original da imagem
- `scale-down`: utiliza o menor tamanho entre `none` e `contain`

Para compreender melhor esses valores, vamos utilizar uma área com dimensões definidas:

```css
img {
  width: 500px;
  height: 300px;
  border: 0.25rem solid #ff0000;
}
```

A partir dessas dimensões, podemos controlar como a imagem será ajustada dentro desse espaço. Para visualizarmos o uso do espaço, acrescentamos uma borda vermelha.



**Utilizando `cover`:**

```css
img {
  width: 500px;
  height: 300px;
  border: 0.25rem solid #ff0000;
  object-fit: cover;
}
```

**Resultado:**

![](https://i.imgur.com/nFzGL3E.png)

Com `object-fit: cover`, a imagem será redimensionada para **preencher completamente a área definida**, mantendo sua proporção original.

Isso significa que **nenhuma área vazia será exibida**, porém partes da imagem poderão ser **cortadas** para que ela ocupe todo o espaço disponível.

Esse comportamento é útil quando **a área precisa ser totalmente preenchida**, como acontece frequentemente com imagens de cards, banners, produtos e galerias.



**Utilizando `contain`:**

```css
img {
  width: 500px;
  height: 300px;
  border: 0.25rem solid #ff0000;
  object-fit: contain;
  
}
```

**Resultado:**

![](https://i.imgur.com/8UuOGF4.png)

Com `object-fit: contain`, a imagem será redimensionada para **caber completamente dentro da área definida**, mantendo sua proporção original.

Isso significa que **nenhuma parte da imagem será cortada**.

Entretanto, se a proporção da imagem for diferente da proporção da área disponível, poderão surgir espaços vazios nas laterais ou na parte superior e inferior.

Esse comportamento é útil quando **toda a imagem precisa permanecer visível**, como acontece frequentemente com logotipos, produtos e imagens que não podem ser cortadas.



**Utilizando `scale-down`:**

```css
img {
  width: 500px;
  height: 300px;
  border: 0.25rem solid #ff0000;
  object-fit: scale-down;
}
```

**Resultado:**

![](https://i.imgur.com/Whpx10P.png)

O valor `scale-down` compara o comportamento de `none` e `contain` e utiliza **a opção que resultar no menor tamanho final da imagem**.

Na prática, isso significa que:

- se a imagem original já couber na área disponível, ela poderá permanecer em seu tamanho original;
- se a imagem for maior do que a área disponível, ela será reduzida para caber;
- a proporção original da imagem será preservada.



### ✅ Resumindo as 3 propriedades:

| Valor        | Comportamento                                                |
| ------------ | ------------------------------------------------------------ |
| `contain`    | Redimensiona a imagem para caber completamente na área       |
| `scale-down` | Mantém o tamanho original quando ele for menor; caso contrário, reduz a imagem |
| `cover`      | Preenche toda a área, podendo cortar partes da imagem        |

A escolha depende do comportamento desejado para a interface.



## 4. **Arredondar os Cantos da Imagem**




A propriedade `border-radius` permite arredondar os cantos de uma imagem.

```css
img {
  width: 500px;
  height: 300px;
  object-fit: cover;
  border-radius: 1rem;
}
```

**Resultado:**

![](https://i.imgur.com/0ec6z8o.png)

Nesse exemplo, todos os cantos da imagem receberão um arredondamento de `1rem`.

Também é possível transformar uma imagem quadrada ou praticamente quadrada em um círculo:

```css
img {
  width: 25%;
  height: auto;
  object-fit: cover;
  border-radius: 50%;
}
```

**Resultado:**

![](https://i.imgur.com/rT6iit7.png)

O valor `50%` aplica um arredondamento suficiente para criar um formato circular quando a largura e a altura possuem o mesmo valor.

Esse recurso é muito utilizado para **fotos de perfil, avatares e imagens de usuários**.

Aplicando o valor de 50% em uma imagem retangular, ela se transformará em uma elipse:

```css
img {
  width: 25%;
  height: auto;
  object-fit: cover;
  border-radius: 50%;
}
```

**Resultado:**

![](https://i.imgur.com/JeQLKTy.png)





## 5. **Adicionar Borda à Imagem**




A propriedade `border` permite adicionar uma borda ao redor da imagem.

```css
img {
  width: 25%;
  height: auto;
  object-fit: cover;
  border: 0.25rem solid #2563EB;
}
```

**Resultado:**

![](https://i.imgur.com/hbNFvxy.png)

Nesse exemplo, a imagem recebe uma borda com:

* `2px`: espessura da borda
* `solid`: estilo da borda
* `#2563EB`: cor da borda

Também podemos combinar `border` com `border-radius`:

```css
img {
  width: 25%;
  height: auto;
  object-fit: cover;
  border: 0.25rem solid #2563EB;
  border-radius: 50%;
}
```

**Resultado:**

![](https://i.imgur.com/0R7mixl.png)

Dessa forma, a imagem terá uma borda e seus cantos serão arredondados.



## 6.  **Adicionar Sombra à Imagem**




A propriedade `box-shadow` permite adicionar uma sombra ao redor da imagem.

```css
img {
  width: 25%;
  height: auto;
  object-fit: cover;
  border: 0.25rem solid #2563EB;
  border-radius: 50%;
  box-shadow: 0 8px 12px rgba(0, 0, 0, 0.3);
}
```

**Resultado:**

![](https://i.imgur.com/6mQu88g.png)

A propriedade `box-shadow` pode receber diferentes valores para controlar a aparência da sombra.

No exemplo:

* `0`: deslocamento horizontal
* `8px`: deslocamento vertical
* `12px`: intensidade do desfoque
* `rgba(0, 0, 0, 0.3)`: cor e transparência da sombra

Esse recurso pode ser utilizado para destacar imagens dentro de **cards, produtos, galerias e outros elementos da interface**.



## 7. **Controlar a Opacidade da Imagem**




A propriedade `opacity` permite controlar o nível de transparência da imagem.

```css
img {
  width: 25%;
  height: auto;
  object-fit: cover;
  border: 0.25rem solid #2563EB;
  border-radius: 50%;
  box-shadow: 0 8px 12px rgba(0, 0, 0, 0.3);
  opacity: 0.8;
}
```

**Resultado:**

![](https://i.imgur.com/IUz0xmO.png)

O valor de `opacity` varia de `0` a `1`:

* `1`: imagem totalmente visível
* `0.7`: imagem parcialmente transparente
* `0.5`: imagem com 50% de opacidade
* `0`: imagem totalmente transparente

É importante utilizar esse recurso com moderação, pois uma opacidade muito baixa pode prejudicar a visualização da imagem.



## 8. **Aplicar Filtros na Imagem**




A propriedade `filter` permite aplicar efeitos visuais diretamente sobre a imagem.

Na tabela abaixo, você confere os principais filtros oferecidos pelo CSS:

| Filtro          | Função                               | Exemplo                         |
| --------------- | ------------------------------------ | ------------------------------- |
| `grayscale()`   | Transforma a imagem em tons de cinza | `grayscale(100%)`               |
| `blur()`        | Aplica desfoque à imagem             | `blur(5px)`                     |
| `brightness()`  | Controla o brilho da imagem          | `brightness(0.8)`               |
| `contrast()`    | Controla o contraste da imagem       | `contrast(1.5)`                 |
| `saturate()`    | Controla a saturação das cores       | `saturate(1.5)`                 |
| `sepia()`       | Aplica um efeito sépia               | `sepia(100%)`                   |
| `hue-rotate()`  | Altera os tons das cores da imagem   | `hue-rotate(180deg)`            |
| `invert()`      | Inverte as cores da imagem           | `invert(100%)`                  |
| `opacity()`     | Controla a transparência da imagem   | `opacity(0.5)`                  |
| `drop-shadow()` | Adiciona uma sombra à imagem         | `drop-shadow(4px 4px 6px #000)` |
| `none`          | Remove todos os filtros aplicados    | `none`                          |

Para exemplificar o uso dos filtros, vamos criar uma **galeria de imagens**, utilizando a mesma imagem várias vezes na página e aplicando um **filtro diferente em cada cópia**. Dessa forma, será possível visualizar e comparar, de maneira prática, o efeito produzido por cada uma das funções da propriedade `filter`.

```css
/* Filtros */

.filter-none {
  filter: none;
}

.filter-grayscale {
  filter: grayscale(100%);
}

.filter-blur {
  filter: blur(5px);
}

.filter-brightness {
  filter: brightness(0.6);
}

.filter-contrast {
  filter: contrast(1.8);
}

.filter-saturate {
  filter: saturate(2);
}

.filter-sepia {
  filter: sepia(100%);
}

.filter-hue {
  filter: hue-rotate(180deg);
}

.filter-invert {
  filter: invert(100%);
}

.filter-opacity {
  filter: opacity(50%);
}

.filter-shadow {
  filter: drop-shadow(8px 8px 6px #555);
}
```

**Resultado:**

![](https://i.imgur.com/xoz3syt.png)

Note que cada filtro **produz um efeito visual diferente na imagem**, permitindo alterar características como cores, brilho, contraste, saturação, nitidez e transparência.

Também podemos combinar diferentes filtros:

```css
img {
  width: 25%;
  height: auto;
  object-fit: cover;
  filter: brightness(0.8) contrast(1.2);
}
```

**Resultado:**

![](https://i.imgur.com/rr4ic6z.png)

No exemplo acima, a imagem terá seu brilho reduzido e o contraste aumentado.

Os filtros CSS também podem ser utilizados para **alterar visualmente as cores de uma imagem SVG** inserida na página por meio da tag `<img>`.

> [!NOTE]
>
> **SVG - *Scalable Vector Graphics* (Gráficos Vetoriais Escaláveis)** é um formato de imagem digital baseado em vetores e em código XML. Diferente de arquivos como JPG ou PNG (que usam pixels e perdem qualidade ao ampliar), o SVG usa fórmulas matemáticas para desenhar linhas e formas. Por isso, ele não perde qualidade em nenhum tamanho e o arquivo é muito leve.

Podemos aplicar um filtro para modificar a aparência da imagem:

```css
img {
  width: 25%;
  height: auto;
  object-fit: cover;
  filter: invert(30%) sepia(80%) saturate(1500%) hue-rotate(200deg);
}
```

**Resultado**

**SVG - Original**

![](https://i.imgur.com/z9heWTy.png)

**SVG - Com o Filtro**

![](https://i.imgur.com/ahqiweF.png)

No exemplo acima, uma combinação de filtros é utilizada para produzir uma nova tonalidade para o SVG.

Essa técnica pode ser útil quando temos **um mesmo ícone SVG em diferentes estados ou partes da interface**, evitando a necessidade de criar vários arquivos com cores diferentes.

É importante destacar que o filtro **não altera o arquivo SVG original**. Ele apenas modifica a aparência da imagem quando ela é exibida pelo navegador.

Essa abordagem é especialmente útil para **ícones monocromáticos**, nos quais desejamos aplicar diferentes cores visualmente utilizando apenas CSS.



### ✅ Boas Práticas com filtros



1. **Não exagere:** Um efeito sutil geralmente apresenta uma aparência mais profissional do que um efeito extremo. A menos que esse seja o estilo da sua marca!
2. **Desempenho:** Embora os navegadores modernos utilizam aceleração de hardware para esses filtros, aplicar filtros pesados, especialmente desfoques grandes, em áreas extensas ou em dezenas de elementos simultaneamente pode causar lentidão ou travamentos. Faça alguns testes antes de utilizar.
3. **Tenha uma alternativa:** A imagem original é sua alternativa de fallback. Os filtros funcionam como um aprimoramento progressivo. Se um navegador não oferecer suporte a eles, a imagem sem alterações será exibida.
4. **Acessibilidade é importante:** Nunca utilize apenas um filtro `blur()` para ocultar informações sensíveis, como dados de cartões de crédito, afinal os dados originais ainda estarão presentes no HTML/CSS. Sempre proteja os dados sensíveis no lado do servidor.
5. **Combine com `object-fit`:** Ao trabalhar com imagens que possuem filtros, certifique-se de que elas sejam cortadas e posicionadas corretamente utilizando `object-fit: cover;` e `object-position: center;`.



## Dicas Importantes para trabalhar com Imagens



1. **Sempre que a imagem fizer parte do conteúdo da página, prefira utilizar a tag `<img>`.** Diferentemente de `background-image`, a tag `<img>` representa uma imagem como parte do conteúdo e permite utilizar recursos importantes de acessibilidade e semântica.

2. **Utilize o atributo `alt` nas imagens.** O atributo `alt` fornece uma descrição textual da imagem, sendo importante para acessibilidade e para situações em que a imagem não pode ser carregada.

3. **Evite definir simultaneamente `width` e `height` com valores que alterem a proporção original.** Isso pode deixar a imagem esticada ou comprimida. Quando possível, utilize `height: auto`.

4. **Utilize `max-width: 100%` para imagens responsivas.** Essa regra evita que a imagem ultrapasse a largura disponível do elemento que a contém.

5. **Utilize `object-fit` quando a imagem precisar ocupar uma área com dimensões específicas.** O valor `cover` é útil quando a área precisa ser totalmente preenchida, enquanto `contain` é indicado quando é importante exibir a imagem inteira.

6. **Evite utilizar imagens muito grandes.** Uma imagem com dimensões ou tamanho de arquivo excessivos pode aumentar o tempo de carregamento da página e prejudicar o desempenho.

7. **Prefira formatos modernos e otimizados.** Formatos como **WebP** e **AVIF** geralmente oferecem uma boa relação entre qualidade visual e tamanho do arquivo.

8. **Utilize `border-radius`, `box-shadow` e `filter` com moderação.** Esses recursos podem melhorar a apresentação visual, mas o excesso de efeitos pode prejudicar a clareza e a consistência da interface.

9. **Escolha uma imagem adequada ao espaço onde ela será apresentada.** Imagens com proporções muito diferentes da área disponível podem exigir cortes quando `object-fit: cover` for utilizado.

10. **Não utilize imagens apenas para substituir informações que poderiam ser apresentadas como texto.** Informações importantes devem continuar disponíveis de forma textual e acessível.

Essas práticas ajudam a manter as imagens **responsivas, acessíveis, visualmente adequadas e alinhadas às boas práticas de desenvolvimento web**.
